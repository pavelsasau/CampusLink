Interface web développée dans le cadre de notre formation à Paris Ynov Campus.

Le projet CampusLink est un mini-système d'information destiné à la gestion des salles, des équipements et des incidents techniques d'un campus.

**## Présentation**

CampusLink permet de consulter différentes informations concernant le campus et de signaler des problèmes liés aux équipements ou aux salles.

Pour la première partie du projet, nous avons réalisé une interface statique en HTML et CSS.

Cette première version permet de mettre en place la structure et le design général du site avant d'ajouter les fonctionnalités dynamiques dans les prochaines étapes.

**## Fonctionnalités**

**### Accueil**

\- Page d'accueil du site

\- Accès aux différentes parties du projet grâce au menu de navigation

**### Salles**

La page Salles permet de consulter les différentes salles du campus.

**### Équipements**

La page Équipements permet de consulter les équipements présents sur le campus.

**### Incidents**

La page Incidents permet de consulter les incidents présents sur le campus.

Les incidents sont présentés sous forme de cartes avec notamment :

\- Le nom de l'incident

\- La salle concernée

\- La criticité

\- Les informations concernant le problème

**### Déclaration d'un incident**

La page de déclaration permet de remplir un formulaire afin de signaler un problème.

Le formulaire contient :

\- Le titre de l'incident

\- La salle concernée

\- L'équipement concerné

\- La criticité

\- La description du problème

\- Un bouton pour déclarer l'incident

**### Navigation**

Le site possède un menu permettant de naviguer entre les différentes pages :

\- Accueil

\- Salles

\- Équipements

\- Incidents

\- Signaler un problème

**## Design**

L'interface utilise un design commun à l'ensemble du site.

Le design comprend :

\- Une image de fond

\- Des blocs transparents

\- Des bordures arrondies

\- Des ombres

\- Un effet de flou

\- Une navigation centrée

\- Des cartes pour afficher les informations

Le formulaire de déclaration utilise également un bloc centré afin de rester cohérent avec la page des incidents.

**## Responsive**

Le site utilise différentes propriétés CSS afin de s'adapter aux différentes tailles d'écran.

\- Flexbox

\- flex-wrap

\- max-width

\- width

**## Accessibilité**

La structure HTML utilise notamment des labels associés aux champs du formulaire.

Les différents champs de la déclaration possèdent des identifiants permettant d'associer correctement les labels aux éléments du formulaire.

**## FR01 - HTML/CSS**

La première partie du projet consiste à réaliser une interface statique en HTML et CSS.

Cette partie comprend :

\- La structure HTML des différentes pages

\- La mise en forme avec CSS

\- La navigation entre les pages

\- La page des salles

\- La page des équipements

\- La page des incidents

\- Le formulaire de déclaration d'un incident

À ce stade, le formulaire est uniquement visuel et ne permet pas encore d'enregistrer réellement un incident.
